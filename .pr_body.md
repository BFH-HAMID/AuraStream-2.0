## 🚀 What's New

### 🧠 AI Agent with Persistent Memory (`agent_brain.py` — NEW)
The Telegram agent now **knows your channel**:
- **Channel profile** — niche, tone, audience, language, region (`/settings set niche tech reviews`)
- **Custom instructions** — `/settings custom always open with a shocking fact`
- **Learned facts** — `/remember my audience loves short tutorials`
- **Full production history** — every produced/uploaded video with links (`/history`)
- Every AI reply (chat, scripts, suggestions) is conditioned on this memory — the agent gets more personalized over time

### 💡 Topic Suggestions with Analysis (`/suggest`)
- Pulls Google Trends + your niche + past videos → **5 topic ideas with virality scores /10, reasons and target audience**
- **Inline buttons**: tap 🎬 Produce or 📜 Script right from the suggestion
- Gemini → HF Mistral → offline heuristics fallback chain

### ⬆️ YouTube Upload from Telegram (`/upload last`)
- **Headless OAuth**: bot sends a Google sign-in link → you paste the redirect URL back → token cached in `token.pickle`
- Works with `client_secrets.json` OR `GOOGLE_CLIENT_ID` + `GOOGLE_CLIENT_SECRET` secrets (HF Space friendly)
- Auto-uploads title/description/tags from the remembered production + thumbnail + pinned comment

### 💬 Sentiment-aware Comment Replies (`/comments [video_id] [max]`)
- Reads comments, analyzes sentiment + emotion, writes empathetic replies, posts them, reports a summary (scanned / replied / errors)

### 🎞️ 1080p Full HD Engine
- Exact **1920×1080** rendition picking (Pexels → smallest-above-target → Pixabay `large`), uniform scale+center-crop, 30fps, adaptive 8 Mbps H.264
- "Video Resolution" selector in the dashboard

### 🤖 Free-text like a human
"make a video about X", "suggest topics", "upload my last video", "reply to comments" — the intent router (keyword fast-path + LLM JSON fallback) handles plain sentences, Bengali triggers included ("video banao").

### 🤗 HF Space Deployment Ready
- `docker-entrypoint.sh`: `RUN_TELEGRAM_AGENT=true` runs bot + dashboard in one container
- `DEPLOY_HF_SPACE.md`: step-by-step free deployment guide (secrets table, `app_port: 8501`, UptimeRobot keep-alive, limits)
- Non-root, HF-compatible permissions, healthcheck respects `PORT`
